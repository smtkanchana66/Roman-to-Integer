# Roman Numeral to Integer Converter
This Python script converts Roman numerals into their integer equivalents. It handles both basic and complex Roman numeral structures.

## Features
- Converts Roman numerals (e.g., `LXVI`) to integers.
- Supports all valid Roman numerals from 1 to 3999.
- Simple and efficient algorithm.

## How to Use
1. Clone the repository:
   ```bash
   git clone https://smtkanchana66/Roman-to-Integer.git
   cd Roman-to-Intege
2. Run the python file:
   ```python
   python3 solution.py
   ```
